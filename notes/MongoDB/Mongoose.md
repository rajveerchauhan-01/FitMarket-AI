Why do we use Mongoose instead of only the MongoDB driver?

A strong answer is:
"Mongoose is an ODM (Object Data Modeling) library for MongoDB. It sits on top of the official MongoDB driver and provides schemas, models, validation, middleware, population, and a cleaner API, making database interactions more structured and easier to maintain."

Why do we use dotenv?

A strong answer:
"dotenv loads environment variables from a .env file into process.env. It allows us to keep sensitive information like database URLs, API keys, and JWT secrets outside the source code, improving security and making it easy to use different configurations for development, testing, and production."
